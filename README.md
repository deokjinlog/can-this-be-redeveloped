# can-this-be-redeveloped

> **"이 재개발 물건, 사도 되나?"** — 재개발·재건축 물건을 살 때 새 집(입주권)을 실제로 받을 수 있는지를 **근거와 함께** 판정한다. 예측이 아니라 **요건·자격 판정**이다.

`can`(요건·자격을 충족하나) 만 답하고 `will`(실제로 진행·완공될까) 은 예측하지 않는다.
조합 갈등·정치·시장은 아무도 확답 못 한다. 딱 잘라 말할 수 있는 건 "요건은 충족한다"까지다.

```bash
python check.py "관악구 신림동 675-159"
```
```

[2] 구역      🟢 신림7 재개발 77,935㎡ · 고시 2024-10-14   고시도형
[2b] 단계     정비구역지정 (27% 지점)                     정보몽땅

              🧱 미착공 추정  ✓ 게시 단계와 일치

```

**API 키가 필요 없다.** 주소 해석도 좌표도 내려받은 공개 파일로 로컬에서 푼다.

## 두 게이트 — 둘 다 통과해야 새 집

```
새 집을 받는다 = [A 이 지역이 재개발 될 수 있나] AND [C 내가 사서 입주권 자격이 되나]
```

**A. 요건** (`criteria_engine.py`) — 정비구역 지정 요건. 이미 지정·고시됐으면 행정청이 이미
심사해 인정한 상태이므로 **다시 추정하지 않는다.** 미지정이면 노후도·면적·선택요건으로 판정한다.

**C. 자격** (`engine.py`) — 투기과열지구에서 사면 조합원 지위를 승계받나(입주권), 현금청산인가.
돈이 걸린 곳은 여기다. 프리미엄과 입주권을 통째로 날리는 실패 모드가 이쪽이다.

| 사업 | §39② 제한이 걸리는 시점 | 그 전이면 |
|---|---|---|
| 재건축 | 조합설립인가 후 | 🔓 자유 양도 (예외 불필요) |
| 재개발 | 관리처분계획인가 후 | 🔓 자유 양도 (예외 불필요) |

제한이 걸린 뒤에는 13개 예외 중 하나가 필요하다. 재건축 3년 트리는 인가 일자로 자동 판정되고,
나머지는 등기부·초본이 있어야 한다.

## 판정 규율

이 프로젝트가 다른 계산기와 다른 지점은 전부 여기 있다.

- **미확인은 미확인** — 값이 없으면 추측하지 않고 `확인필요` 로 두고, 필요한 자료를 알려준다.
  "판단불가 N개" 대신 **"이 자료만 주세요"** 로 수렴시킨다.
- **반올림 금지** — 준공일 미상은 노후로도 양호로도 세지 않고 `[하한, 상한]` 구간으로 낸다.
  구간이 기준선을 걸치면 Fact 를 발급하지 않는다.
- **유리한 쪽으로도 반올림하지 않는다** — 접도율은 현황도로가 빠져 요건에 *유리하게* 나올 수 있어,
  기준선 ±5%p 안이면 확정하지 않는다.
- **잰 범위가 다르면 확정하지 않는다** — 길·법정동 단위 노후도는 실측이지만 구역 경계가 아니다
  → `〔잠정〕`. 구역 경계로 재면 그때 확정한다.
- **틀리느니 비운다** — 구역↔사업장 매칭에서 번호가 어긋나면 붙이지 않거나 경고를 단다.
- **'자료 없음'을 '없음'으로 읽지 않는다** — CSV 범위 밖이라 건물이 0동인 것과 철거된 것은 다르다.
- **근거등급** P0 조문 › P1 원본 › S1 기관게시 › T 진술. 최약 링크로 하향, T 단독 MET 불가.
- **4값** MET / NOT_MET / INSUFFICIENT(자료 주면 해결) / CONFLICT(전문가로).

## 원문 대조에서 나온 것들

기준은 전부 조문·원본에서 오는데, 대조해보니 실제 오류가 여럿 있었다. 기록해둔다.

**조문** (`law.py` 로 국가법령정보센터 원문 대조 → 미검증 0)

- 3년 트리를 `§37②` 로 인용했는데 실제는 **§37③1~3호** (§37②는 공공재개발 상가 임대)
- 준공지연(3호)을 재건축 전용으로 처리했는데 조문은 "재개발·재건축의 **토지**" — 재개발도 해당
- 장기보유(§39②4호)에 **"1세대 1주택자로서"** 요건이 빠져 있었다
- 경매·공매를 넓게 봤는데 "**국가·지자체·금융기관** 채무 불이행"으로 한정된다
- **§39② 본문 괄호** — '양수'에서 상속·이혼은 제외라, 그렇게 취득했으면 제한 자체가 안 걸린다

→ 예외 8개 → **13개**.

**데이터**

- 지적 도형면적과 대장 대지면적을 비교할 때 **'외필지수'로 집단을 갈라야 한다.**
  안 가르면 밴드가 두 배로 부풀려진다 — 외필지 1+ 는 오차가 아니라 개념 차이(건축 대지 vs 필지).
  단일 필지 9,664건 실측 90% 구간 → 실제면적 ∈ 도형 × [0.897, 1.042]
- 고시도형은 이력을 함께 담아 **같은 땅에 옛 구역과 현행 구역이 겹친다.**
  고시번호에 박힌 고시일자로 세대를 가른다(서울 78건)
- 위치로 못 찾은 구역을 이름으로 붙이면 **다른 땅의 같은 번호 구역**에 매달린다.
  오매칭을 걷어내니 관악구 매칭 20→11건으로 줄었지만 **교차검증 어긋남 8→0**
- "지정된 구역은 지금도 노후도 60% 이상"은 **틀린 전제** — 지정요건은 지정 *시점* 기준이라
  준공된 구역이 노후 0%인 게 정상이다

**UI** — 파이썬 테스트가 다 통과해도 JS 포팅은 따로 깨진다. jsdom 회귀를 붙였고 2건을 고쳤다.


계약일·등기일 사이에 인가가 있으면 그 자리에서 경고한다.

```bash
python test_cases.py     # C 자격 (13예외 · dual-run)      15/15
python criteria_test.py  # A 요건                           5/5
python aging_test.py     # 노후도 집계 규율                 10/10
python geo_test.py       # 좌표변환·SHP파서·구역판정        11/11

#                                                          71/71
```

판정 엔진은 **표준 라이브러리만** 쓴다 — SHP 파서, 횡메르카토르 투영, 데이텀 변환,
point-in-polygon 전부 직접 구현했다. jsdom 은 UI 테스트 전용 개발 의존이다.

## 한계

- **공공데이터로 안 되는 것** — 등기부(취득일)·주민등록초본(거주기간)은 개인 서류라 앞으로도
  자동화되지 않는다. 사용자 업로드가 유일한 경로다
- **접도율** — 지목 `도` 기준이라 사도·통행로 같은 현황도로가 빠진다. 도로 도형이 들어오면 승격
- **진행단계·인가일자** — 근거등급 S1(기관 게시), 관보 고시 원문이 아니다.
  추진경과를 공개하지 않은 조합도 있다(관악구 36곳 중 20곳만)
- **구역 해제 이력** — 현행 고시도형이라 해제 여부는 확인할 수 없다. 세대 구분으로 완화했을 뿐이다
- **수집 범위** — 지금은 관악구(연속지적도·표제부). 구역·단계·법령은 서울 전체
- 참고용이며 법률자문이 아니다
