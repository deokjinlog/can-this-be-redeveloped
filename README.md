# can-this-be-redeveloped

> **"이 재개발 물건, 사도 되나?"** — 재개발·재건축 물건을 살 때, 새 집(입주권)을 실제로 받을 수 있는지를 **근거와 함께** 판정한다. 예측이 아니라 **요건·자격 판정**이다.

**철학 — 판정 대신 신호+근거+확인리스트, 미확인은 미확인, 판단은 코드가.** "될 수 있나(요건·자격)"만 판정하고 "될까(실현)"는 예측하지 않는다.

## 왜 `can`(될 수 있나)이고 `will`(될까)이 아닌가
- **`can`** = 요건·자격 충족 여부 (노후도·연한·§39②/§37) → **우리가 판정하는 것.**
- **`will`** = 실제로 진행·완공될지 (조합 갈등·정치·시장) → **예측이라 우리는 안 함.**

딱 잘라 말할 수 있는 건 "요건은 충족한다(=될 수 있다)"까지. 실제로 될지는 아무도 확답 못 한다.

## 두 게이트 (둘 다 통과해야 새 집)
```
새 집을 받는다 = [A 이 지역이 재개발 될 수 있나] AND [C 내가 사서 입주권 자격 되나]
```

### A. 요건 모듈 — `criteria_engine.py` (✅ 3/3) + `aging.py` (✅ 10/10)
"이 지역·집이 **정비구역 지정 요건**을 충족하나" (노후도·연한).
- **지역 노후도**(필수): 노후·불량건축물 비율 ≥ 서울 60%(재정비촉진 50%). ✅ 조례 검증
  → **`aging.py` 가 건축물대장 표제부 CSV 전수로 직접 계산**(아래).
- **건물 연한**: 준공 후 20~30년(조례), RC 공동주택 30년. ✅ 검증
- **선택요건**(하나 이상): 호수밀도·접도율·과소필지 — 별표 수치 조례별 상이 → `verified=False`, **확인필요** 처리(잠정치만 표시)

### C. 자격 모듈 — `engine.py` (✅ 6/6, "입주권 신호등")
"투기과열지구에서 사면 **조합원 지위를 승계**받나(입주권) vs **현금청산**당하나" (도시정비법 §39②·시행령 §37 8예외).
- OR(8예외)·각 예외 AND, 4값(MET/NOT_MET/INSUFFICIENT/CONFLICT), 확인필요 반올림 금지, 근거등급, source_span. (`rubric.md` 참조)

## 공통 출력 계약
- **4값**: MET / NOT_MET / INSUFFICIENT(자료 주면 해결) / CONFLICT(전문가로)
- **미검증 기준은 추측 금지** → 확인필요. 검증값만 verified=True.
- **요청자료로 수렴**: "판단불가 N개" 대신 "이 자료만 주세요."
- **3색 신호**: 될 수 있음 🟢 / 미달 🔴 / 확인필요 🟡

## 노후도 전수집계 — `aging.py`

정보몽땅 게시치(S1)를 받아쓰는 대신, **건축물대장 표제부 CSV 전수**(P1)로 노후도를 직접 센다.

```bash
python aging.py                                   # 법정동 전체 요약
python aging.py --by road --top 15                # 길(도로) 단위 노후율 랭킹
python aging.py --by road --find 양지6길 --sens     # 그 길 상세 + 경과연수 기준 감도
python aging.py --by road --find 양지6길 --judge --area 23000   # 요건모듈 A 로 판정까지
python aging.py --json data/aging-sinlim.json     # 웹/서버용 집계본
python aging_test.py                              # 10/10
```

CSV 는 [건축HUB](https://open.eais.go.kr) → 건축물대장 → **표제부** 로 받아 프로젝트 폴더에 두면 자동 인식(용량 커서 gitignore).

**핵심 규율 — 준공일 미상은 반올림하지 않는다.**
노후도를 단일값이 아니라 `[하한, 상한]` 구간으로 낸다.

| | 뜻 |
|---|---|
| 하한 | 미상을 **전부 양호**로 본 값 (`노후/전체`) |
| 상한 | 미상을 **전부 노후**로 본 값 (`(노후+미상)/전체`) |
| 하한 ≥ 60% | 🟢 MET 확정 |
| 상한 < 60% | 🔴 NOT_MET 확정 |
| 구간이 60%를 걸침 | 🟡 확인필요 — **Fact 를 발급하지 않는다** |

경과연수 기준도 조례마다 20~30년이라 `--sens` 로 감도를 병기한다(검증된 `표준30` 만 판정에 사용, `완화20`·`구조혼합`은 미검증 표시).

**측정 단위 한계(명시)**: 집계 단위는 법정동/도로/지번블록이지 **정비구역 경계가 아니다.**
실제 구역 노후도는 지정된 경계 안에서 다시 세야 하며, 이 값은 그 대리지표다 — 출력에 항상 함께 찍힌다.

실측(서울 관악구 신림동 전수, 17,622동):

```
🟢 노후·불량 동수 비율  61.6% ~ 61.9%   (기준 60%)   ← 준공일 미상 48동
   노후 연면적 비율     42.8% ~ 42.9%   (선택요건 기준 60%)
   과소필지(90㎡미만)    1.4% ~ 38.4%   ← 대지면적 미상 6,226필지 → 잠정·확인필요
```
