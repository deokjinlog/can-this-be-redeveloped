# can-this-be-redeveloped

> **"이 재개발 물건, 사도 되나?"** — 재개발·재건축 물건을 살 때 새 집(입주권)을 받을 수 있는지를 근거와 함께 판정한다.

`can`(요건·자격을 충족하나) 만 답하고 `will`(실제로 진행·완공될까) 은 예측하지 않는다.
조합 갈등·정치·시장은 아무도 확답 못 한다. 딱 잘라 말할 수 있는 건 "요건은 충족한다"까지다.

```bash
python check.py "관악구 신림동 675-159"
```
```
[1] 주소     난향길 42 · PNU · 좌표                        로컬 건물DB
[2] 구역     신림7 재개발 77,935㎡ · 고시 2024-10-14        고시도형
[2b] 단계    정비구역지정 (27% 지점)                        정보몽땅
[3] 건물     덕원빌라 1997 · RC · 10세대                    건축물대장 API
[4] 구역내   노후 86.9% · 과소필지 26~33% · 접도율 46.3%     지적 × 대장 (포착률 99.9%)
             미착공 추정 — 게시 단계와 일치
─────────────────────────────────────────────
 A: 이미 정비구역으로 지정됨
 C: §39② 미발동 — 지금은 서류 없이 승계 가능
```

API 키가 필요 없다. 주소 해석도 좌표도 내려받은 공개 파일로 로컬에서 푼다.

## 두 게이트 — 둘 다 통과해야 새 집

```
새 집을 받는다 = [A 이 지역이 재개발 될 수 있나] AND [C 내가 사서 입주권 자격이 되나]
```

**A. 요건** (`criteria_engine.py`) — 정비구역 지정 요건. 이미 지정·고시됐으면 행정청이 심사해
인정한 상태이므로 다시 추정하지 않는다. 미지정이면 노후도·면적·선택요건으로 판정한다.

**C. 자격** (`engine.py`) — 투기과열지구에서 사면 조합원 지위를 승계받나, 현금청산인가.
돈이 걸린 곳은 여기다. 프리미엄과 입주권을 통째로 날리는 실패 모드가 이쪽이다.

| 사업 | §39② 제한이 걸리는 시점 | 그 전이면 |
|---|---|---|
| 재건축 | 조합설립인가 후 | 자유 양도 (예외 불필요) |
| 재개발 | 관리처분계획인가 후 | 자유 양도 (예외 불필요) |

제한이 걸린 뒤에는 13개 예외 중 하나가 필요하다. 재건축 3년 트리는 인가 일자로 자동 판정되고,
나머지는 등기부·초본이 있어야 한다.

## 판정 규율

이 프로젝트가 다른 계산기와 갈리는 지점은 전부 여기 있다.

- **미확인은 미확인** — 값이 없으면 추측하지 않고 `확인필요` 로 두고 필요한 자료를 알려준다.
  "판단불가 N개" 대신 "이 자료만 주세요" 로 수렴시킨다.
- **반올림 금지** — 준공일 미상은 노후로도 양호로도 세지 않고 `[하한, 상한]` 구간으로 낸다.
  구간이 기준선을 걸치면 Fact 를 발급하지 않는다.
- **유리한 쪽으로도 반올림하지 않는다** — 접도율은 현황도로가 빠져 요건에 *유리하게* 나올 수 있어
  기준선 ±5%p 안이면 확정하지 않는다.
- **잰 범위가 다르면 확정하지 않는다** — 길·법정동 단위 노후도는 실측이지만 구역 경계가 아니다
  → `〔잠정〕`. 구역 경계로 재면 그때 확정한다.
- **틀리느니 비운다** — 구역과 사업장 매칭에서 번호가 어긋나면 붙이지 않거나 경고를 단다.
- **안 재는 요건을 '없는 요건'으로 읽지 않는다** — 영 별표1 제2호의 선택요건은 목이 가~자
  9개다. 우리가 값으로 재는 건 그중 넷(과소필지·접도율·호수밀도·노후연면적)이라, 넷이 다
  미달이어도 `미달` 이 아니라 `확인필요` 다. 방재지구·최저고도지구 같은 목이 남아 있다.
- **'자료 없음'을 '없음'으로 읽지 않는다** — CSV 범위 밖이라 건물이 0동인 것과 철거된 것은 다르다.
- **근거등급** P0 조문 › P1 원본 › S1 기관게시 › T 진술. 최약 링크로 하향, **T 단독 MET 불가**.
  손으로 입력한 연도는 진술(T)이라 그것만으로 확정되지 않는다 — 서류를 넣어야 P1 이 된다.
  (NOT_MET 은 낼 수 있다. 막는 건 근거 없는 '충족' 뿐이다.)
- **4값** MET / NOT_MET / INSUFFICIENT(자료 주면 해결) / CONFLICT(전문가로).

## 대조하며 고친 것들

기준은 전부 조문·원본에서 오는데, 대조해보니 실제로 틀린 곳이 여럿 있었다. 같은 실수를
반복하지 않으려고 남긴다.

**조문** — `law.py` 로 국가법령정보센터 원문과 대조 (미검증 0)

- 3년 트리를 `§37②` 로 인용했는데 실제는 §37③1~3호 (§37②는 공공재개발 상가 임대)
- 준공지연(3호)을 재건축 전용으로 처리했는데 조문은 "재개발·재건축의 **토지**" — 재개발도 해당
- 장기보유(§39②4호)에 "1세대 1주택자로서" 요건이 빠져 있었다
- 경매·공매를 넓게 봤는데 "국가·지자체·금융기관 채무 불이행" 으로 한정된다

**조례** — 수집한 관악구 고시문이 인용한 조항을 자치법규 원문과 대조

- **호수밀도 분자를 '세대수'로 셌다.** 조례 §2⑤ 는 "1헥타르당 건축되어 있는 **건축물의 동수**"
  이고, 가목이 "공동주택·다가구주택은 세대수가 가장 많은 층의 1세대를 1동" 이라고 못박는다.
  아파트 한 동에 100세대여도 동수는 그 층의 세대수다. 세대수로 세면 **준공된 아파트 단지가
  초고밀 노후지로 읽힌다** — 신림1구역 191호/ha → 12동/ha, 신림2구역 267 → 15.
  대조군은 신림8구역 공람공고문이 같은 구역의 두 숫자를 다 준 것: 조례기준 745호 vs
  거주가구수 2,195(비율 0.339). 새 산정식을 관악 표제부 전체에 돌리면 0.387 로 붙고,
  종전 방식은 1.000 이었다
- **재개발 접도율의 도로 폭은 4m 가 아니라 6m.** §2⑩ 의 일반 정의는 4m 지만, §6①2나 가
  "제2조제10호에도 불구하고 주택접도율의 도로 폭은 6미터 이상으로 한다"(2024.5.20 신설).
  고시문이 그대로 증언한다 — 2024-04-23 [35193] "폭 4m이상", 개정 뒤 2024-09-23 [36266]·
  10-02 [36327] "폭 6m이상". 관악 전역 52.6% → 32.8%, 신림7 60.9% → 46.3%.
  4m 는 주거환경개선구역(§6①1나) 몫이라 따로 보관한다
- **요건표의 출처를 '조례 별표1' 로 적어놨었다.** 조례 별표1 은 공동주택 노후기간표고,
  요건표는 **시행령 별표1 제2호**(정비계획의 입안대상지역)다. 그리고 `law.py` 가 조문만
  받고 별표를 안 받아서 그 원문이 통째로 빠져 있었다 — 엔진의 핵심 근거인데
- **선택요건이 4개가 아니라 5개다.** 영 별표1 제2호아목 — "지하층의 전부 또는 일부를
  주거용도로 사용하는 건축물의 수가 전체 건축물 수의 2분의 1 이상"(반지하 50%)이 빠져
  있었다. 표제부엔 지하층 *용도* 가 없어(지하층 보유 79.7% 는 대부분 주차장) 값은 못 채우고,
  요건 자리만 만들어 `층별개요` 를 요청 자료로 낸다
- **재는 선택요건이 다 미달이면 '미달' 을 선언했다.** 목이 9개인데 넷만 재고 결론을 낸
  셈이라 잘못된 `NOT_MET` 이었다 → `확인필요` 로 바꿨다
- **노후 동수 75% 이상이면 선택요건을 갖춘 것으로 본다.** 조례 조문이 아니라 서울시
  운영기준이라 근거등급 S1 로 밝힌다 — 관악구 고시 후보지모집안내문(2024-10-02)
  "※ 노후동수 75%이상인 경우 : 시 조례(선택요건) 갖춘 것으로 봄"
- **노후·불량건축물 기준을 '일괄 30년' 으로 쓰고 있었다.** 조문 어디에도 그런 기준은 없다.
  조례 §4① 은 넷으로 갈린다 — RC계 공동주택은 별표1(준공연도×층수, 20~30년), 그 외
  공동주택 20년, 비공동주택 RC계 30년, 나머지 20년. 특히 **단독주택은 제2호가목이
  명시로 제외**해서 철근콘크리트여도 20년이다(건축법상 다가구주택도 단독주택).
  관악 17,795동 중 단독주택이 10,549동이라 이 하나로 전역 노후도가 61.6% → 67.0%,
  신림7 은 86.9% → 90.6% 로 올랐다. 노후도는 필수요건이라 그만큼 오판이었다.
  같은 일괄 30년이 **세 군데** 있었다 — 구역 집계(`aging`), 내 건물 판정(`criteria_engine`),
  웹 UI 의 JS 포팅. 규칙을 `criteria_engine.old_years()` 한 곳으로 모으고 나머지는 부른다.
  주용도·구조·층수를 모르면 가능한 기준을 다 돌려 `20~30년` 구간으로 두고, 걸치면
  `확인필요` 로 건축물대장을 요청한다
- **조례 §4② 도 빠져 있었다** — "과소필지 안의 건축물로서 2009년 8월 11일 전에 건축된
  건축물" 은 나이와 무관하게 노후·불량이다. 넣었지만 관악 구역들에선 추가되는 동이 0 이다
  (과소필지의 옛 건물은 이미 20년을 넘겼다). 필지 밴드가 90㎡ 를 걸치거나 사용승인일
  없이 연도만 2009 면 정하지 않는다
- **웹 UI 는 파이썬 엔진의 JS 포팅이라 위 수정이 하나도 안 들어가 있었다.** 선택요건이 다
  미달이면 `미달` 을 내던 것, 반지하 요건, 75% 면제, 호→동 단위를 같이 옮겼다
- §39② 본문 괄호 — '양수' 에서 상속·이혼은 제외라, 그렇게 취득했으면 제한 자체가 안 걸린다

예외가 8개에서 **13개**가 됐다.

**데이터**

- 지적 도형면적과 대장 대지면적을 비교할 때 '외필지수' 로 집단을 갈라야 한다. 안 가르면 밴드가
  두 배로 부풀려진다 — 외필지 1+ 는 오차가 아니라 개념 차이(건축 대지 vs 필지).
  단일 필지 9,664건 실측 90% 구간 → 실제면적 ∈ 도형 × [0.897, 1.042]
- 고시도형은 이력을 함께 담아 같은 땅에 옛 구역과 현행 구역이 겹친다.
  고시번호에 박힌 고시일자로 세대를 가른다 (서울 78건)
- 위치로 못 찾은 구역을 이름으로 붙이면 다른 땅의 같은 번호 구역에 매달린다.
  오매칭을 걷어내니 관악구 매칭이 20건에서 11건으로 줄었지만 교차검증 어긋남은 8건에서 0이 됐다
- "지정된 구역은 지금도 노후도 60% 이상" 은 틀린 전제 — 지정요건은 지정 *시점* 기준이라
  준공된 구역이 노후 0%인 게 정상이다

**우리 코드**

- UI 하단에 "T 단독은 MET 불가" 라고 써놓고, 취득연도·거주연도는 손입력을 그대로 충족으로 냈다.
  파이썬 엔진은 코드로 강제하는데 JS 포팅에는 등급 개념 자체가 없었다 → `docparse.py` 로 서류를
  읽어 P1 을 확보하고, 손입력은 T 로 남겨 확정되지 않게 했다
- 파이썬 테스트가 다 통과해도 JS 포팅은 따로 깨진다. jsdom 회귀를 붙였고 2건을 고쳤다

## 실행

```bash

python check.py "..." --등기부 deungi.txt --초본 chobon.txt   # 서류로 소유·거주 확정
```

웹 UI 는 주소 조회로 구역·단계·§39② 게이트·구역내 실측을 한 번에 채우고, 계약일과 등기일
사이에 인가가 있으면 그 자리에서 경고한다. 서류는 붙여넣으면 값과 인용을 함께 읽는다.

## 한계

- **개인 서류** — 등기부(취득일)·주민등록초본(거주기간)은 발급을 자동화할 수 없다.
  사용자가 원문을 주면 `docparse.py` 가 읽는다. 서류 양식은 발급처·시점에 따라 다르고,
  못 읽으면 경고를 낸다
- **접도율** — 지목 `도` 기준이라 사도·통행로 같은 현황도로가 빠진다. 도로 도형이 들어오면 승격.
  조례 §2⑩ 단서(연장 35m 이상 막다른 도로는 폭 6m)는 지적도로 '막다른' 판정이 안 돼 미적용
- **호수밀도** — 정의는 조례 §2⑤ 로 확정했지만 표제부에 층별 세대분포·건축면적·무허가가 없어
  값은 근사다. 근사값으로 선택요건을 MET 으로 올리지 않는다 — 화면에만 보여준다
- **반지하 비율** — `floors.py` 가 건축물대장 층별개요를 구역 단위로 받아 채운다. 조회한
  구역만 값이 있고, 안 받은 구역은 전부 '미상' 이라 Fact 를 발급하지 않는다
- **고시문의 구역 제원** — 관악구 166건을 뒤졌지만 노후도·접도율·과소필지 수치가 든 문서는
  없었다. 온라인엔 공고문만 올라오고 현황조사표가 든 정비계획서 본문은 구청 현장 공람이다.
  숫자가 있는 건 신림8구역 공람공고문의 호수 745·면적 103,912㎡ 뿐
- **진행단계·인가일자** — 근거등급 S1(기관 게시)이지 관보 고시 원문이 아니다.
  추진경과를 공개하지 않은 조합도 있다 (관악구 36곳 중 20곳만)
- **구역 해제 이력** — 현행 고시도형이라 해제 여부는 확인할 수 없다. 세대 구분으로 완화했을 뿐이다
- **수집 범위** — 연속지적도·표제부는 관악구. 구역·단계·법령은 서울 전체
- 참고용이며 법률자문이 아니다
